% fig_pooling_tikz.tex -- all eight MIL pooling heads in one place.
%
% Source of truth: seanet/pooling.py, and Section 6 of this report.
%
% Every head shares the SAME template (Eq. common_template):
%     z_j --> attention branch  A(z_j)        <- SLOT 1
%     z_j --> classifier        p_j
%     evidence  g_j^k = a_j^k p_j^k
%     g  -->  aggregate over time             <- SLOT 2  --> Ybag^k
%     g  -->  interpretation Phi (the SAME numbers, not a second branch)
%
% So a head is fully described by what it puts in slot 1 and slot 2.
% The figure draws the template once, then one row per head: what goes in
% slot 1, what goes in slot 2, and a small bar picture showing WHICH of the
% T evidence values actually reach the bag score.
%
% The bar picture uses the same made-up evidence profile in every row, so
% the rows differ only by the aggregator -- that is the whole point.
% Dark orange = counts fully, pale = counts a little, grey = dropped.
%
% SIZING: keep the natural width near 17 cm and the height near 19 cm.
% \resizebox then shrinks by about 0.82, so \small lands near 7.5 pt and
% the whole thing still leaves room for the caption on one page. Widen the
% drawing and every label gets smaller, so keep the columns where they are.
%
% Node names are global in tikz, so every row prefixes its nodes.
% =====================================================================
