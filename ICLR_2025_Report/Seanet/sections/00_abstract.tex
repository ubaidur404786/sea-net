In tiny deep learning, previous models were black boxes. They only predicted classes or assigned labels to time series data without providing any reason for it. The \millet{} framework showed that Multiple Instance Learning (MIL) pooling turns a standard backbone into a model that explains itself. The network scores every time step, and those scores \emph{are} the explanation. However, the issue is that this model was not made for tiny applications.

During this internship, I built \seanet{}, which is our baseline architecture. In this model, we use a Temporal Convolutional Network (TCN) as the main encoder along with different pooling techniques. My main contributions are the multi-scale depthwise-separable TCNs that create the \seanet{} family of encoders (the base encoder plus the gated, bottleneck, input-gate, spike/trend and reconstruction variants). I also contributed a family of seven MIL pooling heads: class-wise conjunctive, softmax conjunctive with a learnable temperature, adaptive class-wise, top-$k$ conjunctive, attention-max, per-class gated attention, and dual-stream conjunctive.

I evaluated 72 model combinations on the \webtraffic{} dataset and the 85 \ucr{} datasets used by \millet{}. I measured both classification quality (accuracy, loss) and explanation quality (AOPCR, NDCG@$n$). Most of the sweep uses one random seed, but the four models that carry the main comparison were re-run over 3 random seeds. My best variant, \texttt{seanet\_bottleneck\_topk}, reaches 0.947 accuracy on \webtraffic{}, compared to 0.887 for the re-trained \millet{} baseline. At the same time it uses 10$\times$ fewer parameters (41\,K against 424\,K) and improves the NDCG score (used to evaluate explanations) from 0.677 to 0.773. The best model of the whole sweep, \texttt{seanet\_gated\_mean\_topk}, reaches 0.955 accuracy with 62\,K parameters. On the wider \ucr{} archive the re-trained \millet{} baseline is still ahead on average, which I report and discuss rather than hide. The code that produced every number in this report is at \url{https://github.com/ubaidur404786/sea-net}.
